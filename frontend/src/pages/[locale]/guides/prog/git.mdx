## <Translate key='page.guides.git.toc.branching' />

## <Translate key='page.guides.git.toc.troubleshooting' />

<a name="angre-feil" />
### <Translate key='page.guides.git.toc.undoErrors' />

<Translate key='page.guides.git.troubleshooting.undoIntro' block />

- <Translate key='page.guides.git.troubleshooting.undoChanges'/>

```bash
git restore filnavn.txt  # Angre endringer i fil
git restore .            # Angre alle endringer
```

- <Translate key='page.guides.git.troubleshooting.undoCommits'/>

```bash
git reset --soft HEAD~1  # Angre sist commit, behold endringer
git reset --hard HEAD~1  # Angre sist commit, slett endringer
```

> <Translate key='page.guides.git.troubleshooting.undoWarning'/>

- <Translate key='page.guides.git.troubleshooting.revert'/>

```bash
git revert HEAD                 # Revert siste commit
git revert abc123               # Revert spesifikk commit
```

<a name="stash-endringer" />
### <Translate key='page.guides.git.toc.stashChanges' />

<Translate key='page.guides.git.troubleshooting.stashIntro' block />

```bash
git stash       # Stash alle endringer
git stash -u    # Stash inkludert untracked files
git stash list  # Se alle stashes
git stash pop   # Hent tilbake siste stash
git stash drop  # Slett stash
```

<Translate key='page.guides.git.troubleshooting.stashDesc' block />

<a name="undersøk-historikk" />
### <Translate key='page.guides.git.toc.examineHistory' />

<Translate key='page.guides.git.troubleshooting.historyIntro' block />

```bash
git log                # Full historikk
git log --oneline      # Kort oversikt
git log --graph --all  # Visualiser alle branches
git log --decorate     # Viser referanser
git log -p             # Viser endringene
git log -n 4           # Viser de 4 siste commitene
git --no-pager log     # Unngå scary Vim keybinds :)
```

<Translate key='page.guides.git.troubleshooting.historyCombine' block />

```bash
git --no-pager log --graph --all --oneline --decorate
```

### <Translate key='page.guides.git.cheatSheet.branches' />


### <Translate key='page.guides.git.cheatSheet.fork' />

```bash
# Sett opp fork
git clone git@github.com:ditt-navn/repo.git
git remote add upstream git@github.com:original/repo.git

# Hold deg oppdatert
git fetch upstream
git switch main
git pull upstream main

# Lag feature branch og push
git switch -c feature/ny-funksjon
git push -u origin feature/ny-funksjon

# Forbered for merge
git fetch upstream
git rebase upstream/main
git push --force-with-lease origin feature/ny-funksjon
```
